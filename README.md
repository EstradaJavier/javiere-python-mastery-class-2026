## 🎯 The Mission

This repository is a structured Python learning project built to strengthen fundamentals, develop clean coding habits, and gradually move into more advanced Python topics.

The goal is not just to collect random code samples, but to build a real learning path with lessons, notes, demos, tests, and projects that show steady growth over time.

## 🗺️ Learning Path

| Module | Focus Area | Status | Highlights |
|--------|------------|--------|------------|
| 01 | Basic Python lessons | In progress | Foundations, beginner-friendly teaching examples |
| 02 | Intermediate Python lessons | In progress | Callback functions added first |
| 03 | Advanced Python lessons | Planned | Future advanced topics |
| Bonus | Additional lessons and demos | Active | FizzBuzz and PyScript experiments |

## ✅ Current Progress

Recent progress in the repository includes:

## 🧪 Testing

This project uses `pytest` for lesson-based testing.

Example command:

```bash
python3 -m pytest tests/basic/test_callback_functions.py -v
```
